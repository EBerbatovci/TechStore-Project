# Project Management Evidence

Lab Course 1 requires Git and Trello evidence. The repository contains the Git history, but the Trello board must be attached by the project team because it lives outside the source code.

## Trello Board

Add the public or instructor-accessible Trello link here before submission:

```text
Trello board: <paste-link-here>
```

## Recommended Trello Lists

- Backlog
- To Do
- In Progress
- Code Review / Testing
- Done

## Recommended Labels

- Backend
- Frontend
- Database
- Security
- Bug
- Documentation

## Evidence Checklist

- Screenshot of the full board.
- Screenshot showing labels/statuses.
- Screenshot showing card comments or member activity.
- Screenshot or export showing completed tasks.
- Link added to `README.md`.
